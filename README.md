# AIAIAI – אייאייאיי פתרונות AI

אתר תדמית מלא ומודרני לחברת AI ישראלית.

## Stack טכנולוגי

- **Next.js 15** (App Router)
- **TypeScript**
- **TailwindCSS** עם תמיכה מלאה ב-RTL
- **Framer Motion** לאנימציות
- **Lucide React** לאייקונים

## סקשנים

- **Hero** – מסך פתיחה עם particles, dashboard הולוגרפי ו-typing effect
- **Services** – כרטיסי שירותים עם Glassmorphism
- **Demo** – דמו אינטראקטיבי: WhatsApp bot, AI Dashboard, Voice Agent
- **Why Us** – יתרונות עם counter אנימציה
- **Testimonials** – לקוחות עם carousel אוטומטי
- **Contact** – טופס צור קשר + כפתורי WhatsApp/Phone
- **Footer** – ניווט מלא + CTA

## התקנה והרצה

```bash
npm install
npm run dev
```

## פריסה ל-Vercel
